name: daily-crypto-report
description: Generate the weekly crypto market report every Saturday at 11:00 (Europe/Paris), covering the previous 7 days
---

Run the DailyCryptoReport skill to generate this week's crypto market intelligence report, covering the previous 7 days. Use the Skill tool to invoke "DailyCryptoReport". Follow all instructions in the skill — run GrokSearch queries in parallel with the 7-day window, fetch news sites, run web searches, assemble the weekly report (Top 10, up to 10 items per section), and save to ~/Documents/personal-knowledge-vault/raw/reports/crypto/YYYY-MM-DD.md (today's date).
